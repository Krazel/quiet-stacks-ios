# Quiet Stacks 0.17.9 (1)

CC0. El WAV coincide exactamente con la muestra G escuchada por el usuario,
con atenuación hasta −12 dBFS. Conserva el volumen de efectos configurado.

colocación. La categoría libre de suelo/mesa usa el nuevo impacto de madera.
Se mantienen rendimiento, ilustraciones, catálogo y guardados de 0.17.8.
